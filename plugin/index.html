2Tagging
Create the tagging groups, assign your wall/roof elements to them in GEN NX, then Refresh. Roof: WWroof+LWroof = gable, ROOF = monoslope (auto-detected). End walls: ENDWALL0 = first end, ENDWALL1 = last. Loads apply to TAGGED elements only.

3Wind parameters
The model's position is auto-detected (any plan location, base at any level) — only the ridge direction must be given.
Full set uses all checked directions for wind + MWFRS; check all four for the complete 58-case sequence.
4Preview & apply
Apply is non-destructive: only this run's own load cases are replaced on each element — Dead/Live/EQ and other wind directions already in the model are preserved.
